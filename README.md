## 📌 Project Overview

In this project our team has been tasked to investigate Converged Cloud and High-Performance Computing (HPC) Platforms.

The goal is to explore how cloud computing technologies can be utilized in an HPC platform to deliver scalable, efficient, and flexible computational infrastructure for research, analytics, and enterprise applications.

---

### Technologies Investigated

| Technology | Purpose / Notes |
|------------|----------------|
| **OpenStack** | Provides a cloud platform for managing compute, storage, and networking resources in a flexible and scalable manner |
| **Kolla Ansible** | Automates OpenStack deployment and service management using containerized services |
| **Ironic** | Enables bare metal provisioning for HPC nodes, allowing physical hardware to be treated as cloud resources |


This project focuses on deploying a high-performance computing (HPC) cluster using both **bare metal servers** and **virtual machines**, leveraging:

- **OpenStack**
- **Kolla Ansible**
- **Ironic (Bare Metal Provisioning)**
- **Bifrost**
- **Switch-level networking & hardware configuration**

The end goal is to:
- Investigate Cloud Computing platform **Openstack**
- Configure Hardware at CSIR Lab
- Configure the Networking
- Deploy Ironic using Kolla Ansible
- Deploy a fully functional bare-metal OpenStack cluster
- Deploy the cluster on VMs using OpenStack    
- Benchmark both setups  
- Compare performance and efficiency

## 🗂 Project Breakdown (6-Week Plan)

### **📅 Week 1 — Foundations**

### **📅 Week 2 — Hardware Discovery (Complete ✔)**
- Visit CHPC Lab

### **📅 Week 3 — Networking Setup (Complete ✔)**
- Cable all nodes into correct topology  
- Label cables & ports

---

### **📅 Week 4 — Bare Metal Deployment (Complete ✔)**

- Deploy Ironic via Kolla Ansible  
- Setup Bifrost  
- Register bare metal nodes

---

### **📅 Week 5 — Cluster Deployment & Benchmarking**

### **📅 Week 6 — Virtual Machine Cluster Deployment & Comparison**
